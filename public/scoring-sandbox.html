Scoring Sandbox

Dev tool — not part of the main app. Runs a curated set of good/ok/bad questions through the same consolidated scoring functions the live interview page uses (reading-page-scoring.js), for each of the 6 personalities, so you can eyeball whether grading changes actually make the system fairer before shipping them.

(requires node index.js running locally — this page must be opened via that server's URL, not file://)
